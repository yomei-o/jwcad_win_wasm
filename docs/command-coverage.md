# 原典のメニュー項目と移植の対応

`decomp/res/menu.txt` の MENUITEM を全部。`tools/mkcoverage.sh` が作ります。
**動く** = 送ると 命令が替わる・ダイアログが出る・図面が変わる・アクションが立つ。
**反応なし** = そのままでは何も変わらない（理由を右に）。**フロントエンド** = ファイル窓・印刷など、
`src/main_win32.c` と `index.html` の仕事。**別の形** = 原典の右クリックメニューや 内部用の項目で、
移植は同じ働きをバーの釦などで持つか、持たない。
