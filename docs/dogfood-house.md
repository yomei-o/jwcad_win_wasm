# 二階建ての間取りを 作ってみた記録

`tests/house_test.c` が、ページが送るのと同じ命令・クリック・キーだけで、二階建ての間取りを作ります
（外壁二重の矩形・間仕切り・建具・寸法・部屋名（日本語）・ハッチ・レイヤグループ二つ・PDF 印刷）。
できた図面は `tests/data/house2f.jww`（`tests/house_test.exe --make` で作り直し）。テストは
作り直した図面を 保存→読み戻し して、この図面と 要素数・順・レイヤグループ・線の位置を比べます。

作りながら 引っかかった所（バグでなく 原典どおりの 手順だが 知らないと詰まるもの）:

| 場面 | 手順 | 引っかかり |
|---|---|---|
| 寸法 | 最初の問い「引出し線の始点」（どこでも）→ 寸法線の位置 → 始点 → 終点。続けて始点（L）・連続の終点（R） | 「引出し線の始点」を聞かれるので 三点でよいと思うと 要素が増えない |
| 建具 | 命令を選ぶと 建具選択窓が 描画のときに開く。クリックのほか **Tab**（次のファイル）・**数字**（その頁の n 番目）・**Enter**（頁の一番目）・Esc | 以前は クリックだけで キーボードでは進めなかった（直した） |
| ハッチ | 線を (L) で順に指し、**最初の線をもう一度** 押すと輪が閉じる。ピッチ箱（1411）に値を入れて **実行 (1148)** | 箱をクリックしても 前の値は選択されない（既定 10）。実行を押さないと 何も描かれない。実行すると 輪の中に 線が入る |
| 文字 | 先に文字を打ってから 位置をクリック。日本語は 一字ずつ（`jw_key_u`）送る。Esc で打ち終わり | 命令を替えるまで 打った字は 次のクリックでも 置かれ続ける |
| 範囲選択（文字） | 二点目を **右** ボタンにしないと 文字が入らない | 左で囲むと 線だけ |
| 階の切り替え | レイヤグループの升目を **右クリック** で 書込グループにする | 左クリックは 表示／非表示の循環で 書込先は変わらない |
| 保存 | 寸法は 保存すると 寸法図形の部品（寸法値の文字・点）が 増えて 読み戻される | 保存直後の要素数は 作った直後と違う（正しい） |

直したもの: 建具選択窓のキーボード操作（Tab・数字・Enter）。
