## 基本設定のほかの箱

`app_kihon` の OK は いま 上の二つだけを 効かせる。ほかの箱（逆順描画 2444・ソリッドを先に描画 2406・
ソリッド描画順 1525〜1527 ほか）は 窓に 出るだけで 何も しない。`FUN_00481d50`（描画本体）が
どのグローバルで 順序を 変えるかは デコンパイルの `DAT_00a0c7a8` などから 引ける見込みだが、箱と
グローバルの 対応（`CGeneralPage` の DDX 表）を まだ 見つけていない。

**2026-10-14 夜に分かったこと**（逆コンパイルの読み）: 箱は `CSonotaPage`（DDX `FUN_005ce2a0`、
機械語から引いた）で、2444 → `+0xb20`、2405 → `+0xb24`、2406 → `+0xb28`、2860 → `+0xbb0`、
ソリッド描画順 1525〜1529 → `+0xed0`〜`+0xee0`。頁の作り手 `FUN_005cc7e0` が
`DAT_00a0b410`（文書）の値から初期値を作る:

| 箱 | 文書の値 |
|---|---|
| 逆順描画 2444 | `+0x82b8 != 0` |
| 画像･ソリッドを最初に描画 2405 | `+0x82a8 != 0` |
| ソリッドを先に描画 2406 | `+0x82a8 == 2` |
| ソリッド描画順 1525〜1529 | `+0x82ac`（0〜6 の七通りを五つの印に割る） |
| 透過属性 2860 | `+0x82b0 != 0`（環境設定の `Draw`/`BmpTOUKA`） |

`+0x82a8`・`+0x82ac` は .jwf の `S_COMM_3` の九つ目の数（一の位が 82a8、十の位が 82ac）、
`+0x82b8` は `S_COMM_4` の三つ目から読まれる（`FUN_00529070`）。**機械語の全体を探しても、描画
本体（`FUN_00481d50` の側）は `+0x82a8`・`+0x82ac`・`+0x82b8` を読んでいない**。読むのは
ハッチ（`CZukeiHachi` 0x671654）・連続線（`CZukeiRenzokuSen` 0x6d5d96、ここで `+0x82a8 = 2` も
書く）・建具（`CZukeiTategu` 0x728669）で、**ソリッドを作るときに要素の並びのどこへ入れるか**に
効く旗らしい、と一度書いたが**違った**: ハッチの `FUN_006715f0` は、図形を拾う順を `+0x82b8` で
前から（`FUN_00572180`/`572140`）／後ろから（`FUN_00572030`/`572100`）に切り替え、`+0x82a8` が
立つと画像・ソリッドを先に回す。**拾う順を描く順に合わせている**ので、やはり描く順の旗で、移植の
2405 の効かせ方（描く順）と食い違わない。描画本体は同じ反復子を使っているはずで、そこで読むのだろう。
逆順描画 2444 は `CJw_winView` の 0x4fc93a で切り替えて札（`FUN_005168b0`）を出すだけで、描画で
どう効くかは未特定。

**前範囲 (1065) と 全選択 (1066) の原典の中身**（2026-10-14 夜、逆コンパイルの読み）: 範囲選択のバー
（`CSentakuDialog`）の釦は番号ではなく **値の組**で命令に渡る（`CMy3Button` が 0x1400+組 を出す。
組 2 → WM_COMMAND 0x8047 → 命令の仮想関数 43 番目、組 3 → 0x8048 → 44 番目、組 6 → 0x1406 → 30 番目、
組 7 → 0x1407 → 31 番目、組 0 → 0x1410 → 34 番目。複写の 31 番目は 作図属性設定 (342) の `FUN_00651bb0`）。

* **43 番目 `FUN_006fcb00` = 1065**: 選択が空でなければ 追加範囲（`+0xb0 = 1`、札 10028）の切り替え。
  **空なら 前範囲**: 全要素のうち `+0x44` の bit 2（選択の印）が残っていて、見える（`FUN_0042dd10`）
  ものを選び直す。一つも無ければ 札 0x1592「データがありません」
* **44 番目 `FUN_006fc520` = 1066**: 空でなければ 除外範囲（`+0xb0 = 2`、札 10029）、空なら 全選択（全部の
  bit 2 を消してから、守られていなくて見えるものに bit 2）

つまり原典の「前」は**直前の選択そのもの**で、要素に残った印から作り直す。**移植は `sel_clear` で
bit 2 も消している**ので、そのままでは前範囲に拾うものが残らない。入れるには、印（`flags` の bit 2 =
桃色に描く）と「いま選んでいる」（`sel`）の持ち方を原典に合わせて分ける必要がある。
